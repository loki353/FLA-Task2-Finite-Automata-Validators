# Task 2 – Finite Automata Validators

**Author:** Lokesh Bakkola

## Overview
This project demonstrates finite-automata-inspired validation for:
- Four-digit ATM PINs
- Password policy checks
- Basic email-format checks

## Run
```bash
python validators.py
```

## Tests
```bash
python -m unittest -v
```

## Files
- `validators.py` – validation functions and sample output
- `test_validators.py` – unit tests

**Note:** The email and password checks are practical validators inspired by regular-language constraints; they are not complete production-grade standards implementations.
